# Knot 1.1.119

## Fixes

- **A friend's voice no longer goes silent until someone rejoins.** Call audio
  plays through a Web Audio route that stayed on the first voice track it was
  built from. When the friend's voice track changed inside the call, the route
  kept playing the old one. It now follows the current voice track.
- **Ending a screen share always stops Windows sound capture.** Stopping a share
  while its sound was still starting left capture running in the background,
  and the next share's sound came up a few seconds late.

## Windows 10 computer sound

- **Windows 10 can share computer sound.** Knot normally records every app's
  sound except its own, which needs a recent Windows update. Without it, Knot
  now falls back to recording everything the PC plays. That includes Knot's own
  playback, so people watching may hear an echo of their own voice. The share
  status says "whole-PC sound" while this is in use.
- Turn the fallback off under **Settings → Screen sharing → Whole-PC sound when
  isolated capture is unavailable**. The **Test isolated computer audio** button
  now says which mode the PC uses and shows the Windows error code when the
  isolated mode is unavailable.
