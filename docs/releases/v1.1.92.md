# Knot 1.1.92

## Highlights

- Replaces the wall of large theme cards with a compact, scannable Appearance
  list using previews, subtle dividers, and a clear selected indicator.
- Removes repetitive boxed messages from Aurora, Arcade, Cozy, Cyberdeck,
  Library, and Studio in favor of open lanes, spacing, dividers, and restrained
  accent lines.
- Keeps intentional message containers in Bento, Comic, Retro, Brutalist, and
  Paper, where the shape is part of the theme concept.
- Adds regression checks for the compact picker and the distinction between
  open message lanes and intentionally card-based themes.
