# Knot 1.1.106

## Highlights

- Linux computer sound no longer blasts the speakers when a share starts. The
  loopback parks on a muted dummy sink, then fades up on the real speakers.
- Friend hears desktop audio more reliably. Capture keeps running if the local
  return path fails, PCM stays aligned, and the viewer fades the reserved
  audio lane instead of playing silence at full volume.
- Native AV1 stays the live picture for NVIDIA NVENC and AMD VA-API. Dark
  desktops are not treated as a dead decoder. VP9 is only used if AV1 never
  paints a frame.
- 4K AV1 is advertised as high-tier so VA-API paints instead of a black canvas.
