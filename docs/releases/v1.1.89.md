# Knot 1.1.89

## Highlights

- Adds group DMs and group calls for up to 20 members, with invite, leave,
  rejoin, compact-call, and persistent-conversation flows.
- Restores account display names, profile pictures, and profile frames after
  login instead of restoring only the DM list.
- Replaces redistributed Emoji.gg originals with keyless API metadata, in-app
  search, a bounded on-demand disk cache, and a Unicode offline seed. Selecting
  a custom emoji inserts it into the composer and never auto-sends it.
- Moves local history to per-message authenticated encrypted SQLite and
  virtualizes long conversations to keep rendering responsive.
- Adds Directory V2 sharding, directory deltas, content-addressed profile and
  server image references, and gradual v1/v2 dual-read migration.
- Deepens direct file-transfer validation, cancellation, flow control,
  persistence, and local privacy-safe throughput diagnostics. The optional
  encrypted object relay remains disabled and is never Worker-proxied.
- Improves 4K60 screen sharing with native AV1/NVENC queue control, motion
  tuning, bounded stale-frame dropping, and latency-aware presentation. The
  deterministic network matrix stays at or below 150 ms p95 in all 108 tested
  conditions without forcing the 100 ms target.
- Adds local-only, allowlisted baseline metrics and network-conditioned
  benchmarks without message text, identifiers, paths, or IP addresses.
- Adds an opt-in, audio-only Realtime-SFU-compatible pilot with automatic P2P
  fallback. It remains disabled in the checked-in Cloudflare deployment.
- Uses an accelerated XWayland UI fallback on affected Linux Wayland systems;
  native screen capture and GPU AV1 encoding remain unchanged.
