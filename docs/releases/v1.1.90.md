# Knot 1.1.90

## Highlights

- Adds five complete visual themes: Paper, Terminal, Aurora, Blueprint, and
  Arcade.
- Gives each theme its own typography, spacing, navigation, message surfaces,
  controls, and settings treatment instead of only changing colors.
- Adds distinctive previews to the Appearance picker and preserves the chosen
  theme between launches.
- Fixes member-list contrast in Paper, right-side navigation overlap in
  Blueprint, and the Settings stacking order in Aurora.
- Adds regression coverage for all 14 themes and their structural layouts.
