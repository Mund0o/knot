# Knot 1.1.105

## Highlights

- Incoming screen shares keep decoding even before you focus the tile, so the
  picture is on the canvas instead of a black fill.
- Linux computer sound moves every app on your speakers into the capture sink,
  not only streams PipeWire labeled a certain way.
- Leaving a call no longer waits on a stuck screen renegotiation. Start voice
  recreates the peer connection if ICE is already dead, so you can rejoin
  without restarting Knot.
