# Knot 1.1.114

## Fixes

- **Joining a call now works.** Once the caller was in the call, their client
  dropped every incoming `connect-request` — including one from the peer they
  were already calling. A joiner whose peer connection was not up yet reconnected
  three times, then asked for the voice relay, and was ignored every time, so
  only the person who *started* the call could get through. Only a call with a
  different person may veto a connect request now; re-pairing the caller resumes
  their voice instead of ending it.
- Joining from the friends list no longer dead-ends. The join target ignored the
  calling peer, so a click disabled the call button, showed "Connecting to start
  voice…" and then never started a connection. It now reaches the calling peer,
  and with nobody to join the button re-enables and says so.
- New `tests/dm-call-join.js` drives the real directory message handler and
  `startCall` to cover both paths, wired into `test:ui`.
