# Knot 1.1.99

## Highlights

- Native screen share no longer starts at the GPU encoder ceiling when the
  other person’s path is still unknown. Without a viewer budget, 4K60 stays on
  the ~16 Mbps formula; a 50 Mbps friend still caps the share at 37 Mbps; a
  known gigabit or LAN path can still use the GPU budget.
- Capture drops stale GOPs after 150 ms instead of waiting until 8 MiB of CBR
  has queued. SCTP admits one in-flight key, not three. File transfers on the
  same connection shrink to a 256 KiB window while a native share is live.
- Computer sound plays when a friend starts sharing. The compact tile is no
  longer silent until you click Watch.
