# Knot 1.1.93

## Highlights

- Keeps native AV1 screen sharing on a 110 ms target with a hard 180 ms
  ceiling. Late frames are dropped or caught up instead of recapturing the
  desktop as H.264.
- Makes window shares start instead of failing a 16:9 monitor preset, refreshes
  Windows window capture at Go Live, and uses the in-app display choice on
  Linux X11. Wayland still consumes the portal in one step.
- Stops leaking the PipeWire share sink when a group or server share is
  canceled while computer sound is starting.
- Home no longer reopens the current DM. Group conversations still count as
  unread when they are open but unfocused.
- Light themes use the same text, field, and muted tokens as the rest of the
  chrome instead of near-white hardcoded colors.
- Opens only https links, delivers group text keys only from the owner or
  current steward, and drops DMs from people who are not friends.
- Gives ICE a 6-second disconnected grace, waits for capture teardown on quit,
  and batches native screen clusters so a live share does not pay one IPC
  round-trip per frame.
