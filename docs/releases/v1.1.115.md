# Knot 1.1.115

## Fixes

- **Linux can connect a voice call to Windows.** Chromium advertised only
  mDNS `uuid.local` host candidates and sent the offer after a short gather
  with no trickle ICE, so Windows never had a reachable address. Calls now
  trickle public and host candidates, wait for a STUN or TURN candidate, drop
  mDNS once a public candidate exists, and disable Chromium's mDNS ICE hiding.
- Friends on the same Wi-Fi are tried on LAN even when they also show as
  online, instead of waiting on a WAN path that Windows cannot complete.
- A lower-id joiner no longer drops a retry or TURN session as glare. Only
  the lower-id host keeps its current room.
- Clicking Call while the peer is reconnecting still starts voice: the
  pending click and call peer survive `preserveCall`, and voice starts when
  ICE connects.
- TURN no longer wipes a configured `PAIR_TURN` server when Cloudflare
  credentials fail, and relay policy is used only when TURN URLs exist.
- Linux silent-audio no longer adds extra transceivers after a 48 kHz
  AudioContext failure, which desynchronized Chrome's answer m-lines.
