# Knot 1.1.116

## Fixes

- **Voice calls connect again.** 1.1.115 dropped mDNS candidates once STUN
  returned a public address, then added a second trailing newline. Chromium
  rejected that offer and that answer as an invalid SDP line, so starting a
  call and joining one both failed. The public SDP now keeps a single
  trailing newline.
