# Knot 1.1.110

## Highlights

- Share computer sound is monitored locally through the capture AudioWorklet
  instead of an unmuted PipeWire loopback, so the sharer hears desktop audio
  without a speaker blast.
- The call log records in-depth share-audio diagnostics (PipeWire mute/move,
  PCM peak, viewer bind) next to the existing Diag lines.
- Native AV1 no longer ends the share after one failed send or a brief empty
  read from the recorder.
