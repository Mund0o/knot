# Knot 1.1.98

## Highlights

- Joining a voice call no longer crashes. Chromium rejects two Opus lines that
  share payload type 111 with different stereo/bitrate settings in one ICE
  bundle. Voice stays 111; computer sound uses 112. Incoming offers from 1.1.97
  and earlier are remapped so they can still connect.
- Watch Together stays off the waiting-for-friend stage. The YouTube field no
  longer sits on top of the waiting animation, and the “they’ll pop in” copy
  is no longer clipped.
