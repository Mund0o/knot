# Knot 1.1.95

## Highlights

- Watch together in a DM, group, or server voice room. Paste a YouTube link or
  pick the same file on each computer. Play, pause, and seek stay in sync over
  the encrypted P2P data channel. YouTube uses youtube-nocookie; local files
  never leave your machines.
- Friends on the same Wi-Fi show an On this Wi-Fi chip. If Knot cloud is down,
  you can still call and send text over that local link using saved friend keys.
- Incoming calls play a short mallet ringtone so a ring is easy to recognize.
