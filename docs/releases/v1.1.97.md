# Knot 1.1.97

## Highlights

- The local profile photo paints again. A multi-megabyte GIF is served through
  `knot-avatar://` instead of a CSS `data:` URL, which Chromium refuses past
  2 MB. Zoom crops inside the circle instead of scaling the photo past it.
- Sign-in survives updates. A leftover Pair session is merged into Knot without
  minting a new identity or replacing the photo sidecar with a JPEG thumb or
  the text `file:v1`.
- Decrypt failure is not a write. A missing `settings.key` is not replaced
  while encrypted settings still exist, and a raw key backup is kept so the
  OS vault can fail without wiping the session.
- Create account stays hidden when this computer already knows the username.
  “Too many account sessions” no longer forces a password prompt, and a live
  session’s 90-day timer refreshes on reconnect.
