# Knot 1.1.94

## Highlights

- Stops an empty directory snapshot from wiping friends, direct messages, and
  servers. Missing roster arrays keep the live list; an explicit empty snapshot
  asks for a full snapshot instead of clearing the Friends page and DM rail.
- Directory V2 no longer hides a populated primary identity behind a blank
  shard record. Snapshots fall back to the stored friend, server, and group
  lists, rewrite the empty V2 record, and still show a friend whose profile
  failed to load.
- Caches the last good roster locally so Friends landing and DMs both return
  after a restart, instead of waiting on a later snapshot that never arrives.
- Leaves encrypted server membership keys in place when a blank snapshot has
  no entities, so a recovered server does not rotate or drop its text key.
